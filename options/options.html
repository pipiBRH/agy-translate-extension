Selection & Interaction

Keyboard & Context Menu Shortcuts

  • Right-click page → Translate Page: Translate the entire webpage into your target language
  • Right-click page → Show Original Page: Instantly restore the original webpage content
  • Alt + T / Option + T: Translate selected text immediately
  • Enter: Copy main translation and close
  • 1 / 2 / 3: Copy alternative phrasing line
  • ⌘ + click / Alt + click: Copy and keep window open
  • Esc: Close modal card
